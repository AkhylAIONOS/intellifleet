## Important change in regression B

The wider path search finds an actual 1,487.55 km Delhi → Jaipur → Ahmedabad → Mumbai option for 18,000 kg. The two assigned trucks have 1,800 and 1,500 km ranges. That case is now feasible in the loaded graph; forcing the older “infeasible” result would hide a valid alternative. The network regression verifies load and range instead. A 180,000 kg case verifies safe infeasibility. Existing network edges were not changed to obtain this result.
